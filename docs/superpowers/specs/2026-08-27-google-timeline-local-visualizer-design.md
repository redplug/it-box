# Google Timeline 로컬 시각화 도구 설계

## 상태

설계 승인. 구현 계획 작성 전 사용자 검토 필요.

## 목표

사용자가 Google Maps Timeline 내보내기 파일을 브라우저에서만 분석하고, 선택한 기간의 이동 경로와 요약을 확인할 수 있는 it-box 도구를 제공한다.

## 범위

- 경로: `/google-timeline-visualizer`
- 입력: 사용자가 파일 선택기로 고른 JSON 파일 한 개
- 형식: 현재 Google Timeline 배열 형식과 구형 `semanticSegments` 형식
- 출력: 분석 가능 기간, 선택 기간의 점 수, 이동 거리, 방문한 날짜 수, Canvas 경로 애니메이션
- 날짜 범위: 파일에 포함된 날짜 안에서 시작일과 종료일 선택
- 처리 위치: 브라우저 메모리만 사용. `fetch`, 저장소, URL 쿼리, 클립보드, 다운로드 기능 사용 금지.
- 오류: 파일 읽기 실패, JSON 문법 오류, 지원하지 않는 구조, 좌표 또는 날짜가 없는 선택 기간을 구체적 한국어 문구로 표시.

## 비범위

- Google 로그인, Google API, 위치 권한, 서버 API
- 지도 타일, 지오코딩, 외부 지도 SDK, API 키
- MP4·GIF 생성, 영상 인코더, 공유 링크
- 파일·좌표·요약의 로컬 저장 또는 분석 이벤트 전송
- 원본 저장소 코드, 로고, 스크린샷, 샘플 데이터 복사

## 법적·개인정보 원칙

1. 기능은 독자 구현한다. 참고 대상인 `mahlernim/google-timeline-visualizer`의 MIT 코드 및 자산을 복사하지 않는다.
2. `NOTICE.md`에 참고 저장소, MIT 라이선스, 독자 구현 사실을 기록한다. 사용자에게 출처를 투명하게 알리되 원본과 제휴·승인 관계를 암시하지 않는다.
3. 화면 첫 부분에 다음 고지를 항상 표시한다: “파일과 위치 좌표는 이 브라우저에서만 처리됩니다. 업로드·저장·외부 지도 요청은 하지 않습니다.”
4. 같은 고지에서 타인 위치 정보 무단 업로드를 금지한다.
5. 도구 코드에서 Plausible 또는 다른 분석 호출을 하지 않는다. 사이트 차원의 페이지뷰 분석은 기존 배포 설정의 범위이며 입력 데이터와 분리된다.
6. 지도 타일을 쓰지 않는다. 따라서 CARTO·OpenStreetMap 귀속, 지도 API 약관, 좌표 기반 타일 요청을 만들지 않는다.
7. MP4 인코더를 쓰지 않는다. 따라서 Mediabunny MPL-2.0 코드·고지 의무를 추가하지 않는다.

## 구조

`src/tools/google-timeline-visualizer/` 아래에 세 파일을 둔다.

- `timeline.models.ts`: 외부 JSON을 알 수 없는 입력으로 받고 정규화된 `TimelinePoint` 배열을 반환한다. 순수 함수만 포함한다.
- `timeline.models.test.ts`: 두 지원 형식, 잘못된 JSON 구조, 중복·유효하지 않은 좌표 제거, 날짜 범위와 거리 계산을 검증한다.
- `google-timeline-visualizer.vue`: 파일 선택, 고지, 기간 제어, 오류·요약·Canvas 미리보기를 담당한다. 파일 내용은 컴포넌트 메모리에서만 유지한다.
- `index.ts`: 기존 도구 레지스트리용 메타데이터와 lazy component import를 제공한다.

`src/tools/index.ts`는 새 도구를 `Images and videos` 카테고리에 등록한다. `src/content/tool-guides.ts`는 목적·절차·제한·민감정보 주의사항을 추가한다. `NOTICE.md`는 출처 투명성 고지를 추가한다.

## 데이터 흐름

```
사용자 선택 파일
  → File.text() (브라우저 메모리)
  → JSON.parse
  → normalizeTimeline(input)
  → TimelinePoint[]
  → 선택 날짜 필터
  → 요약 계산 + Canvas 렌더링
```

`TimelinePoint`는 `{ latitude, longitude, timestamp }`만 가진다. 원본 JSON 전체, 파일명, 방문 장소명, 사용자 이름은 정규화 결과에 보존하지 않는다. 좌표는 유한한 범위(latitude -90..90, longitude -180..180)일 때만 채택한다. 같은 timestamp·좌표 반복 값은 제거한다. 시간순으로 정렬한다.

현재 배열 형식은 배열 요소의 위치·시간 필드를 읽는다. 구형 형식은 `semanticSegments` 내부 경로 점과 활동 구간을 읽는다. 지원 구조를 안전하게 인식할 수 없으면 결과를 추측하지 않고 오류를 반환한다.

거리 계산은 연속 지점 사이의 Haversine 거리 합계다. 날짜는 사용자의 브라우저 지역 날짜를 사용한다. Canvas는 외부 지도 없이 최소·최대 좌표를 여백 포함 화면 좌표로 선형 투영한다. 점 수가 1개면 점 하나만 표시한다. 애니메이션은 `requestAnimationFrame`으로 이동 경로를 그리며, 해제 시 취소한다.

## UI 및 오류 처리

도구 화면 순서:

1. 개인정보·권리 고지.
2. JSON 파일 선택 영역. JSON 이외 MIME/확장자 파일은 읽기 전 거부.
3. 분석 가능 기간과 시작일·종료일 입력. 유효 범위를 벗어난 날짜 또는 역순 범위는 비활성화된 결과로 처리.
4. 요약 카드와 외부 지도 없는 Canvas 경로 미리보기.
5. `초기화` 버튼. 메모리의 파일 내용·정규화 지점·선택 상태를 지우고 파일 입력도 초기화.

에러 문구는 원본 파일 내용, 파일명, 좌표를 포함하지 않는다. Canvas에는 장소명, 실제 지도, 좌표 텍스트를 출력하지 않는다.

## 테스트

- 현재 배열 형식에서 유효한 좌표·시간을 시간순 `TimelinePoint[]`로 만든다.
- `semanticSegments` 형식의 활동 경로를 같은 형태로 만든다.
- 범위 밖 좌표, 없는 시간, 중복 점을 제거한다.
- 미지원 구조에서 명시적 오류를 반환한다.
- 날짜 범위 필터는 양 끝 날짜를 포함한다.
- Haversine 거리는 알려진 두 지점에 대해 허용 오차 안에서 계산한다.
- Playwright는 도구 페이지에서 개인정보 고지, JSON 거부 메시지, 샘플 fixture 업로드 후 요약·Canvas 표시, 초기화를 확인한다. fixture는 실제 위치 데이터를 포함하지 않는 가상 좌표만 사용한다.
- `pnpm test:unit`, 새 Playwright spec, `pnpm typecheck`, `pnpm build`를 실행한다.

## 수용 기준

- 네트워크 요청 없이 지원 JSON에서 경로와 요약을 렌더링한다.
- 외부 지도·영상 생성·로그인·저장·외부 의존성이 없다.
- 민감 위치 데이터 로컬 처리와 타인 데이터 주의사항이 첫 화면과 사용 안내에 보인다.
- 잘못된 입력과 빈 기간이 안전하게 설명된다.
- 새 파서·계산 단위 테스트와 UI E2E 테스트가 통과한다.
- `NOTICE.md`에 투명한 참고 고지가 있다.
