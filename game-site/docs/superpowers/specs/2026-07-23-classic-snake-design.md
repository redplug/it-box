# 클래식 스네이크 게임 설계

## 목표

설치 없이 짧게 즐길 수 있는 고전적인 뱀 게임을 게임 사이트에 추가한다. 한 판은 규칙을 설명하지 않아도 바로 이해할 수 있어야 하며, 키보드와 터치 모두에서 자연스럽게 플레이되어야 한다.

## 사용자 경험

- 게임 카드에서 `뱀 게임`으로 진입한다.
- 시작 화면은 제목, 한 줄 설명, 최고 점수, 조작 안내, `게임 시작` 버튼을 보여준다.
- 플레이 중에는 점수와 최고 점수를 상단에 표시하고, 일시정지/재개 버튼을 제공한다.
- 게임판은 반응형 정사각형 20×20 격자다. 뱀은 민트색, 먹이는 코랄색으로 표시하며 어두운 배경과 은은한 네온 효과를 사용한다.
- 데스크톱은 방향키/WASD, 모바일은 게임판 아래의 4방향 버튼과 스와이프를 지원한다.
- 충돌 시 게임 오버 오버레이를 표시하고 점수, 최고 점수 갱신 여부, `다시 하기`를 제공한다.

## 게임 규칙 및 상태

`SnakeState`는 `status`(idle, playing, paused, game-over), 뱀 좌표 배열(머리가 첫 항목), 현재 방향, 다음 방향, 먹이 좌표, 점수를 가진다.

- 시작 시 뱀은 중앙 3칸, 방향은 오른쪽으로 초기화한다.
- 약 150ms 간격으로 다음 방향으로 머리를 한 칸 이동한다.
- 먹이를 먹으면 꼬리를 제거하지 않아 길이가 1 증가하고 점수는 10점 오른다.
- 빈 칸 중 하나를 무작위로 골라 먹이를 다시 배치한다. 뱀이 모든 칸을 차지한 경우 승리 상태로 처리한다.
- 벽 또는 자기 몸과 충돌하면 `game-over`가 된다.
- 반대 방향 전환은 한 틱 안에서 무시해 즉시 자기 몸에 부딪히는 조작을 방지한다.
- 일시정지 중에는 타이머를 멈추고 방향 입력과 이동을 무시한다.

## 구조

- `games/snake/engine.ts`: 순수 상태 생성/이동/충돌/먹이 생성 함수. 랜덤 함수와 시계를 주입할 수 있게 해 테스트 가능하게 한다.
- `games/snake/engine.test.ts`: 초기 상태, 이동, 먹이 섭취, 벽/몸 충돌, 반대 방향 입력, 일시정지 경계를 검증한다.
- `games/snake/Snake.vue`: 타이머 수명주기, 키보드/스와이프/버튼 입력, 최고 점수 저장, 한·영 문구를 담당한다.
- `games/registry.ts`, `composables/useGameLocale.ts`: 게임 카드와 로컬라이즈된 제목/설명을 등록한다.

브라우저 로컬 저장소 키는 `game-site:snake:best`로 하고 현재 기기에서만 최고 점수를 유지한다. 저장소가 없거나 손상된 값이면 최고 점수는 0으로 시작한다.

## 접근성 및 반응형

- 게임판은 `role="grid"`, 각 셀은 장식용으로 처리하고 현재 점수/상태는 `aria-live="polite"`로 알린다.
- 모든 조작 버튼에 한국어/영어 라벨을 제공하고 키보드 포커스 스타일을 유지한다.
- 터치 버튼은 최소 44px 크기, `touch-action: manipulation`을 적용한다.
- 게임판은 작은 화면에서 화면 너비에 맞춰 줄어들고, 큰 화면에서는 최대 520px로 제한한다.

## 검증 기준

- `pnpm test`에서 엔진 테스트가 통과한다.
- `pnpm build`가 성공한다.
- 게임 목록에서 진입해 시작, 이동, 먹이 섭취, 일시정지, 충돌 후 재시작을 확인할 수 있다.
- 새로고침 후 최고 점수가 유지되며 한국어/영어 전환 시 게임 문구가 바뀐다.
