# game.it-box.dev 게임 사이트 설계

## 목표

기존 it-box의 사이드바 중심 UX를 유지하면서 `game.it-box.dev`에 정적 웹게임 3개를 제공한다. 초기 버전은 서버·로그인·온라인 리더보드 없이 브라우저 저장소로 최고 기록을 보존하고, Vercel에서 별도 프로젝트로 배포할 수 있어야 한다.

## 범위

- 숫자 맞히기: 1~100 범위의 숫자를 제한된 횟수 안에 맞히고 시도 횟수를 기록한다.
- 반응속도 테스트: 신호가 나타난 뒤 클릭/탭까지 걸린 시간을 측정한다. 준비 중 조기 입력은 실패 처리한다.
- 틱택토: 로컬 2인용 3x3 게임. 승리·무승부·재시작을 제공한다.
- 공통 게임 셸: 사이드바, 게임 카드, 설명, 재시작, 최고 기록, 모바일 대응, 게임 하단 광고 슬롯.
- 기록은 `localStorage`에 저장하며 개인정보·식별자·서버 전송은 하지 않는다.

## 구조

`game-site/`를 독립 Vite/Vue 앱으로 둔다. 기존 앱을 수정하지 않고 필요한 레이아웃·컴포넌트·게임 엔진만 명시적으로 포함한다. `game-site`는 독립 GitHub 저장소로 추출 가능하며 Vercel에서는 Root Directory를 `game-site`로 지정하거나 별도 저장소를 연결한다. 게임 레지스트리가 라우터와 사이드바를 동시에 생성하여 게임 추가가 파일 2개와 레지스트리 1곳으로 끝나도록 한다.

광고는 승인 전 비활성화한다. 승인 후에도 게임 조작·재시작 버튼과 분리된 하단 고정 높이 슬롯만 사용하고, 라운드마다 새로고침하지 않는다. `VITE_ADS_ENABLED`, publisher ID, 슬롯 ID는 Vercel Production 환경변수로만 설정한다.

## SEO·배포

`VITE_SITE_URL=https://game.it-box.dev`를 사용하고 게임별 title/description/canonical을 동적으로 설정한다. `public/robots.txt`, `public/sitemap.xml`, `public/ads.txt`는 실제 운영자·AdSense 값 확정 후 추가한다. 도메인은 Vercel 프로젝트 Domains에 등록하고 DNS 제공자가 제시하는 CNAME을 사용한다.

## 테스트·품질

게임 규칙은 순수 TypeScript 함수로 분리해 Vitest로 테스트한다. Playwright는 홈→게임 이동, 재시작, 모바일 레이아웃, 틱택토 승리, 반응속도 조기 입력을 검증한다. 게임은 탭 전환 시 타이머/애니메이션을 정리하고 키보드 포커스와 `aria-live` 상태를 제공한다.
