# AdSense 콘텐츠 품질 보강 설계

## 목표

`it-box.dev`를 단순 도구 목록이 아니라 한국어 개발자 도구 사용 경험과 안전성 정보를 제공하는 독창적인 서비스로 보강해, 애드센스의 “가치가 별로 없는 콘텐츠” 거절 사유에 대응한다.

## 진단

- 홈은 도구 카드 중심이며 도구의 선택 기준과 처리 원칙을 충분히 설명하지 않는다.
- `/guides`는 5개의 짧은 요약만 제공한다.
- 도구 페이지마다 목적·입력/출력 예제·제한사항·보안 주의사항이 일관되게 노출되지 않는다.
- `/about`의 운영자·문의처가 비어 있고 개인정보처리방침이 선언 수준이다.
- SPA의 초기 HTML에는 라우트별 제목·설명이 없고 sitemap이 없다.

## 설계

1. `/about`을 실제 운영자 정보, 데이터 처리 원칙, 광고·쿠키, 문의처, GPL 고지를 포함한 신뢰 페이지로 교체한다.
2. `/guides`를 12개의 독창적인 한국어 가이드로 확장하고, 가이드마다 문제 상황·안전한 절차·실수 사례·관련 도구를 제공한다.
3. 홈에 서비스 목적, 브라우저 내 처리 원칙, 안전한 사용 안내, 가이드 진입점을 추가한다.
4. 주요 도구에 재사용 가능한 `ToolUsageGuide`를 연결해 설명·예제·제한·보안 주의사항을 표시한다.
5. index HTML의 사이트 기본 정보, robots.txt, sitemap.xml을 실제 운영 정보에 맞게 정리한다. 라우트별 완전한 SSR 전환은 이번 범위를 넘기고, 우선 콘텐츠 자체와 탐색 가능성을 개선한다.

## 콘텐츠 원칙

- 사실을 과장하거나 애드센스 승인을 보장한다고 표현하지 않는다.
- 민감한 입력을 서버로 전송하지 않는다는 설명은 실제 구현 범위 안에서만 사용한다.
- 도구마다 원본 예제와 실패 사례를 포함한다.
- 다른 사이트의 글을 복사하거나 키워드를 반복하지 않는다.

## 검증

- TypeScript/Vite production build
- sitemap 및 robots 정적 파일 확인
- about/guides 링크와 개인정보 문구 확인
- 변경된 콘텐츠 페이지의 제목·설명·본문 확인
